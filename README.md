# Русификатор для «Learn Programming: Python - Remake»

Полный качественный русификатор для игры **Learn Programming: Python - Remake** в Steam.

## Особенности перевода:
- **100% переведён весь текст**: все 11 глав, введение, интерфейс, настройки, авторы и эпилог.
- **Сохранены оригинальные конструкции кода**: имена функций (print, len, 
ange), ключевые слова (def, 
eturn, if, or, while), типы и значения (True, False, None, *args, **kwargs) строго оставлены на английском языке для сохранения корректной работы всех интерактивных тестов и валидаторов.
- **Поддержка Steam-версии**.

---

## Инструкция по установке:

1. Откройте библиотеку **Steam**.
2. Нажмите правой кнопкой мыши по **Learn Programming: Python - Remake** -> **Управление** -> **Просмотреть локальные файлы**.
3. Скопируйте папку game из этого репозитория (или из архива релиза) в открывшуюся папку игры с подтверждением замены файлов.
4. Запустите игру!
